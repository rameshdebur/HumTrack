# Architecture Decision Records

ADRs capture durable decisions with meaningful consequences. Status values are `Proposed`, `Accepted`, `Deprecated`, or `Superseded`.

Accepted records are not rewritten to change history. A changed decision receives a new ADR and supersession links.
