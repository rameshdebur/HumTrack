# Timing and IMU schemas v1

These JSON Schema 2020-12 documents describe the clocks/mappings, IMU sensors
and camera/lens/orientation metadata associated with HC-IF-TIM-001 binary
streams. Binary layout, integrity and compatibility rules are normative in
`TIMING_AND_IMU_BINARY_CONTRACT.md`.

The schemas distinguish reported, configured, observed, calibrated and
unavailable values. They do not make a camera qualification, synchronization,
analytics, clinical or regulatory claim.
