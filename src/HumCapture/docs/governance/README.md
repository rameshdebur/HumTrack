# HumCapture Governance Index

- `SOFTWARE_LIFECYCLE_AND_AI_ASSISTANCE_PROCEDURE.md` — controlled change,
  AI-assistance, review, verification, version-control, and release workflow.
- `EVIDENCE_CONTROL_POLICY.md` — creation, retention, verification, review, and
  export of engineering and future release evidence.
- `SBOM_POLICY.md` — software-component inventory generation, validation,
  release binding, and supply-chain follow-up controls.
- `templates/CHANGE_REVIEW_RECORD_TEMPLATE.md` — reusable record for change
  classification, traceability, material AI assistance, verification, review,
  supply-chain disposition, and release decision.

These documents establish project controls. They do not independently establish
IEC, ISO, CDSCO, clinical, or certification conformity.
