# HumCapture Agent Governance

This directory defines how work is owned, reviewed, handed off, and promoted into durable project knowledge.

## Start here

- Repository-wide instructions: `../AGENTS.md`
- Component ownership: `ownership.md`
- Task lifecycle: `workflow.md`
- Context selection: `context-policy.md`
- Decision handling: `decision-policy.md`
- Substantial-task handoff: `handoff-template.md`
- Role responsibilities: `roles/`

These files govern agent work; they do not replace architecture, requirements, interfaces, tests, risk controls, or regulatory review.
